# Bodge Job Apps

Public website and privacy-policy hosting for Bodge Job Apps.

## GitHub Pages

Publish from the `main` branch and repository root (`/`).

Expected site URL:

- https://bigben755.github.io/bodge-job-apps/

Findsy privacy policy:

- https://bigben755.github.io/bodge-job-apps/findsy/privacy-policy/

## Structure

- `index.html` — Bodge Job Apps homepage
- `styles.css` — shared site styling
- `findsy/index.html` — Findsy information page
- `findsy/privacy-policy/index.html` — Findsy Privacy Policy

For future apps, create a new folder using the same pattern.
